Questions

Is Gratis free?

Yes. There is no account, no subscription and nothing to pay. Gratis is made by TPN Labs.

Does anything leave the device?

No. Chats and images stay on this device. The only thing Gratis fetches is the model file, once, from Hugging Face.

Which browsers does it work in?

Chrome, Edge, Firefox and Brave. Safari does not support 64-bit WebAssembly memory, so Gratis does not run there.

How large a model can it run?

Gratis raises the working memory ceiling in the browser to 16 GiB, as far as the device allows. It suggests a model that fits this device and shows the memory each model needs before anything downloads.

Does it work without internet?

Yes, after initial setup. Once the model has downloaded, Gratis works offline.

Can other apps connect to it?

No. Gratis runs in the browser sandbox, so it cannot expose a local API or serve other applications. For building with models, TPN Bench is the place.

Who makes Gratis?

TPN Labs, the team behind the TPN subnet on Bittensor and TPN Bench.
